# Shelved structures

Structures Carlton shelved (2026-10-10). They are kept here, outside `structures/`, so the Studio no longer lists them,
and can be moved back with `git mv shelved/<name> structures/`.

- `palisade_*`: "Delete or shelf the palisade line of structures".
- `well_small_*`: the big round well covers it (Carlton, 2026-10-10).
- `road_*`, `bridge_*`: they need to be built dynamically for the situation (terrain, water), not as fixed pieces.
